# Прогоны на офлайн-варианте (qwen2.5:7b через Ollama)

Сняты 6 ноября 2026 на CPU (Intel Mac), до перехода на внешний API. Тогда в событии `SYSTEM_PROMPT_LEAK` было дополнительное поле `tool`, а события карантина писались в `security_events.jsonl`. Сейчас формат строго по заданию: имя инструмента есть только в аудите, а карантин пишется в `injection_events.jsonl`. Актуальные примеры лежат уровнем выше.
